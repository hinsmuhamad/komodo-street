Komodo Street is a GTA 6-style sunset open-world city game. A courier rises through the streets of a sunset coastal city. Drive, run jobs for Pak Bimo, dodge the police, collect all 24 Komodo coins, and become Legenda Jalanan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
